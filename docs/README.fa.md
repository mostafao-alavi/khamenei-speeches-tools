# 🇮🇷 موتور هوشمند خزش، ممیزی و خط لوله پردازش بیانات آیت‌الله خامنه‌ای
### ابزارهای مهندسی داده، دور زدن فایروال (WAF)، غربال‌گری متن کامل و تولید دیتاست‌های هوش مصنوعی

---

## 🎯 معرفی و اهداف مهندسی
این مخزن شامل کلیه کدهای منبع، اسکریپت‌های اتوماسیون و ابزارهای خط‌لوله‌ای است که برای استخراج، ضدانسداد، پاکسازی، ممیزی اصالت و ساخت پایگاه‌داده‌های سخنرانی‌های حضرت آیت‌الله خامنه‌ای در طول ۴۷ سال گذشته توسعه یافته‌اند.

---

## 🛠️ ماژول‌های اصلی خط لوله (`src/`)

### ۱. خزشگر جامع نمایه‌ها (`speech_crawler.py`)
- استخراج و کشف کلیه پیوندها و شناسه بیانات از سال ۱۳۵۷ تا ۱۴۰۴ به همراه بازیابی خودکار و مدیریت صفحات نتایج.
- ذخیره متادیتا در فایل `speech_index.json`.

### ۲. کارگر دانلود مقاوم در برابر فایروال (`download_worker.py`)
- مجهز به فناوری جعل اثر انگشت TLS مرورگر Chrome از طریق کتابخانه `curl_cffi` جهت عبور تضمینی از WAF و فایروال‌های ضدبات سرور.
- پشتیبانی از سیستم توقف هوشمند (Rate Limiting) و تأخیرهای تصادفی (Jitter).
- دانلود همزمان متون Markdown تمیز، کدهای HTML اصلی و اسناد PDF اسکن‌شده رسمی.

### ۳. موتور ممیزی و حذف داده‌های تقطیع‌شده (`dedup_audit.py`)
- پیاده‌سازی قانون سخت‌گیرانه اصالت: بررسی دقیق برای هر تاریخ و حذف اتوماتیک اخبار خلاصه، گزیده‌ها و تحلیل‌های نویسندگان.
- انتخاب کامل‌ترین سخنرانی بر پایه امتیاز ترکیبی (تعداد کلمات، حضور فایل PDF، و کلیدواژه‌های رسمی).

### ۴. صادرکننده فرمت‌های استاندارد هوش مصنوعی (`export_github_dataset.py`)
- تولید سریع فایل‌های فشرده Parquet و فایل‌های استاندارد خطی JSONL.
- ساخت و ایندکس‌گذاری دیتابیس SQLite FTS5 مجهز به توکنایزر اختصاصی زبان‌های راست‌به‌چپ (`unicode61`).

### ۵. هماهنگ‌کننده جامع (`sync_worker.py`)
- اجرای پیوسته، چرخه‌ای و افزایشی کل مراحل پروژه بدون تکرار کارهای قبلی.

---

## 🚀 راهنمای راه‌اندازی و اجرا
```bash
# نصب وابستگی‌ها
pip install curl_cffi beautifulsoup4 pandas pyarrow

# اجرای فرآیند استخراج و ممیزی
python src/sync_worker.py

# تولید مجدد دیتاست‌ها
python src/export_github_dataset.py
```
