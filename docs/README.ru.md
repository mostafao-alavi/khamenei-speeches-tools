# 🇷🇺 Инструменты Сбора Данных и Пайплайн Выступлений Аятоллы Хаменеи
### Python-пакет для Обхода WAF, Аудита Целостности и Генерации Датасетов

---

## 📌 Описание Системы
Этот репозиторий содержит полный стек скриптов на Python для обнаружения, скачивания в обход систем защиты (WAF/CDN), дедупликации и формирования структурированных датасетов.

---

## 🧩 Структура Модулей (`src/`)
- `speech_crawler.py`: Краулер каталогов и индексов с 1979 по 2026 год.
- `download_worker.py`: Загрузчик с эмуляцией TLS-отпечатка Chrome для надежного сбора данных.
- `dedup_audit.py`: Алгоритм аудита, отсекающий краткие пересказы и аналитику.
- `export_github_dataset.py`: Экспорт в форматы Parquet, JSONL и базу данных SQLite FTS5.
